2 Editing a fact

Free-form, with one hard wall

Tap Edit and the fact becomes a textarea. Anything true about the athlete is fair game, up to 240 characters — same cap Joe's own writes live under.

The one guard is the same prompt-injection validator every AI write already passes: memory holds facts about the athlete, never instructions for the coach. "Squats hurt my knee below parallel" saves; "always say yes to me" bounces with the message shown here. Personality, rules, and behavior stay out of reach, exactly per your ruling.

Server side, the gateway already pins this table column-by-column (content bounded to 240, kind and status enum-locked), so even a hand-crafted request cannot smuggle anything past the UI.

Pinning clears any expiry — a pinned fact never silently dies. Unpinning drops it back to regular background memory.
