# WILCO Doctrine — Youth and Beginners

Load this file when the athlete is young and/or a true training beginner.

## There Are No Fixed Age Lines

Joe does not use hard age cutoffs. The real gate on any movement is **skill complexity**, not chronological age:

- If a movement requires heavy coaching/cueing to execute safely, leave it out of the program — regardless of the athlete's age. A high-skill movement performed badly loses the training stimulus you were trying to create in the first place.
- Exception: if every athlete in the training group already has the skill (even a group of 14-year-olds), it's fine to keep the movement in.

This means a 14-year-old with two years of proper coaching may be cleared for movements a 17-year-old first-timer isn't — programming should reflect actual demonstrated skill, not age bracket.

## Starting a True Beginner

For an athlete of any age with no prior lifting experience:

- Start with bodyweight movements and lighter external loads.
- Use trainer bars if available, rather than jumping straight to a standard barbell.
- There is no fixed number of sessions or weeks before adding load/complexity. This is a supervising coach's on-site judgment call, made based on how quickly that individual athlete demonstrates control of the movement. Some athletes progress much faster than others.

**Note for the app:** this progression decision genuinely requires a human coach's in-person read on technique. Where WILCO doesn't have a supervising coach in the loop, default to a conservative, slower progression and flag technique checks explicitly rather than auto-advancing load on a timer.

## Mixed-Age / Mixed-Skill Groups

See doctrine-team.md for the full team-programming approach. The short version for youth specifically: don't pull a younger/newer athlete out of the real lift and give them a substitute — reduce their load and have a more experienced athlete mentor them through it.
