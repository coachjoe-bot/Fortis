# WILCO Doctrine — Team Programming

Load this file when building a program for a coach managing a roster/group rather than a single athlete.

## One Program, Individually Scaled — Not Separate Tracks

Write one shared program for the whole team, scaled per individual by %1RM or RPE. Do not build separate programs/tracks by experience level. The movement pattern and program structure stay constant across the roster; the load and cueing scale to the individual.

Offer exercise variations based on equipment access (e.g., if only half the racks are free, some athletes run a substitution from the standard hierarchy — see doctrine-core.md).

## Determine This First: Training Together or Individually?

Before building the program, establish whether the team trains together in the same time/space or works through the program individually. This changes exercise selection and how movements get executed — a shared training window with shared equipment constrains what's programmable in a way that individual scheduling doesn't.

## The Mixed-Experience-Level Problem

When a freshman and a senior are training in the same session at the same rack:

- **Do not swap the freshman to an easier variation of the lift.** Reduce their load instead, and let them work through the real movement. Avoiding the lift means they never learn it.
- **Use the senior/experienced athlete as a mentor.** Have them help cue and coach the freshman through the lift in real time. This does double duty: it teaches the freshman correctly, and it builds team culture and leadership in the senior.

## Equipment Logistics for Larger Groups

When the group outnumbers available equipment (e.g., 12 athletes, 4 racks, a 45-minute window), structure the session as **rotating stations** — rack work, accessory work, conditioning — with athletes rotating through on a timer rather than one athlete monopolizing a rack for the full session.

- **Hard cap: no more than 4 athletes per rack at a time.** Beyond that gets chaotic and unsafe to supervise.
- Where possible, group athletes into stations by **similar skill/strength level** rather than mixing widely different loads on the same rack — this reduces time lost to loading/unloading plates between turns and keeps the rotation moving.

This is distinct from the freshman/senior mentoring rule above, which applies *within* a shared rack/station when mixed-experience pairing is intentional for coaching purposes. Use grouped-by-level stations when the goal is throughput; use mixed-level pairing when the goal is mentoring a specific athlete through a new lift.

**Standardize:** the movement pattern, the session structure/sequencing, the block phase (everyone on the team is generally in the same phase at the same time, tied to team season timing).

**Individualize:** load (via %1RM or RPE), and equipment-driven exercise substitutions when the group can't all access the same equipment simultaneously.
